# تطوير مشغل السينما الذكي عالي الأداء وعزل موارد العرض (Cinema Focus & Smart Speed Engine)

يهدف هذا التحديث إلى تحويل مشغل الأفلام والمسلسلات إلى مشغل سينمائي خفيف، ذكي، ومؤتمت بالكامل يعمل بضغطة واحدة دون أي أزرار تقنية معقدة، مع قياس سرعة استجابة السيرفرات في الخلفية لحفظ أسرع سيرفر لكل مستخدم، وتوسيع شاشة العرض بحركة مسرحية سلسة، وتفريغ كامل موارد المعالج والذاكرة لصالح الفيلم فور بدء التشغيل.

---

## قرارات المراجعة والتفضيلات المؤكدة

> [!IMPORTANT]
> تم تأكيد التفضيلات التصميمية والوظيفية التالية لتطبيقها بدقة:

- **وضع التركيز السينمائي الكامل (Cinema Focus Mode)**: فور بدء تشغيل الفيلم أو المسلسل، يتم فصل وإخفاء جميع عناصر الخلفية (شبكة الأفلام الخلفية، البانر المتحرك، القصة، طاقم الممثلين، والبطاقات العائمة) لتفريغ الرام والمعالج بالكامل للمشغل.
- **التعامل مع المسلسلات أثناء التشغيل**: عند مشاهدة مسلسل، يُكفى بإبقاء شريط مدمج وأنيق لاختيار الموسم والحلقة أسفل المشغل مباشرة، مع إخفاء باقي تفاصيل الصفحة.
- **إزالة العناصر التقنية من الواجهة**: حذف زر تبديل السيرفرات، زر مانع النوافذ والإعلانات (`sandbox`)، الشارة الحية لحالة الـ Worker، وبطاقة النصيحة العائمة نهائياً من واجهة المستخدم.
- **أولوية الاستخراج والتشغيل**: تجربة استخراج البث عبر السيرفرات الأربعة بالترتيب من الأسرع إلى الأبطأ، وإعطاء الأولوية لتجربة السيرفر التالي على التراجع المباشر للمشغل المدمج (`iframe`).

---

## 1. نظرة عامة والمفهوم الأساسي

- **ماذا يقدم التحديث**:
  1. **محرك قياس سرعة السيرفرات الذكي (Smart Server Speed & Telemetry Monitor)**: يراقب زمن استجابة كل سيرفر (بالملي ثانية) ونسبة نجاحه لكل مستخدم، ويحفظ ترتيب السيرفرات في ذاكرة المتصفح (`localStorage`) بحيث يبدأ دائماً بأسرع سيرفر استجابةً لدى المستخدم.
  2. **اتصال فائق الكفاءة مع Cloudflare Worker ودعم الترجمة**: تحسين طلبات الاستخراج مع ذاكرة تخزين مؤقت سريعة للجلسة، واستخراج مسارات الترجمة (`.vtt` / `.srt`) المرفقة في استجابة الـ Worker وربطها تلقائياً بمشغل الفيديو.
  3. **حركة التوسع المسرحي (Theater Expansion Motion)**: عند تشغيل فيلم أو مسلسل، تتوسع نافذة المشغل بانسيابية لتملأ مساحة العرض السينمائية (`Theater Mode`) مع بقاء زر ملء الشاشة (`Fullscreen`) مستقلاً وفعالاً، بينما يبقى عرض التريلر (`Trailer`) بحجمه القياسي الحالي.
  4. **شاشة التحميل البصرية الصافية (Eye Loader)**: استبدال جميع رسائل ونصوص التحميل بمجسم العين المتحركة المخصص فقط على خلفية سوداء صافية دون أي كتابة.

---

## 2. تجربة المستخدم والتصميم البصري

- **مسار المستخدم (User Flow)**:
  1. يضغط المستخدم على زر **شاهد الآن (Watch Now)**.
  2. تتوسع نافذة العرض بحركة فيزيائية ناعمة إلى الحجم المسرحي العريض، وتختفي في نفس اللحظة قوائم الأفلام الخلفية وتفاصيل القصة والممثلين لتركيز كامل الصفحة على شاشة الفيلم.
  3. يظهر مجسم اللودينغ البصري (العين المتحركة باللون الذهبي `#ffbc03` والأسود) في منتصف الشاشة بدون أي نصوص أو إشعارات.
  4. في الخلفية، يرتب محرك السرعة السيرفرات الأربعة حسب أسرع زمن استجابة مسجل في كاش المستخدم، ويتصل بـ Cloudflare Worker لسحب البث المباشر (أو تجربة السيرفر التالي عند الحاجة) وتشغيله فوراً.
  5. عند تحريك المؤشر أعلى المشغل، يظهر شريط تحكم علوي فائق الشفافية والخفة يحتوي فقط على الأزرار الأساسية (التريلر، العودة للخلفية، ملء الشاشة، والإغلاق).

- **الهوية البصرية وحركة الواجهة**:
  - **شريط التحكم العلوي الشفاف**: خلفية زجاجية خفيفة جداً (`rgba(0,0,0,0.28)`) بعتامة هادئة (`opacity: 0.65`) ترتفع إلى `1.0` عند تمرير الماوس حتى لا تزاحم كادر الفيلم.
  - **التوسع المسرحي مقابل التريلر**:
    - في وضع التريلر: عرض قياسي (`max-w-4xl`).
    - في وضع مشاهدة الفيلم/المسلسل: توسع مسرحي (`max-w-6xl` / `92vw`) مع انتقال سلس.
  - **مجسم التحميل (Eye Loader)**: تطبيق دقيق لحركة `eye` و `eye-color` (`5s infinite`) بأبعاد متوازنة في قلب شاشة المشغل السوداء.

## 3. القرارات الهندسية والمفاضلات التقنية

- **القرار 1: خوارزمية ترتيب السيرفرات حسب السرعة (Latency EWMA Scoring)**
  - *النهج المختار*: حساب المتوسط المرجح لزمن الاستجابة (Exponentially Weighted Moving Average) لكل سيرفر مع مكافأة السيرفر الذي ينجح في التشغيل السريع وتخفيض رتبة السيرفر البطيء أو المتعثر في الكاش المحلي.
  - *لماذا*: لأن سرعة استجابة السيرفرات تختلف حسب بلد المستخدم ومزود الإنترنت لديه؛ فحفظ أسرع سيرفر في كاش المستخدم يجعل التشغيل في المرات القادمة شبه فوري.
- **القرار 2: تفريغ موارد الخلفية أثناء التشغيل (DOM & GPU Unmounting)**
  - *النهج المختار*: إيقاف عرض شبكة الأفلام الخلفية، إيقاف مؤقت السلايد شو، وإلغاء تركيب (Unmount) أقسام القصة والممثلين أثناء نشاط حالة المشاهدة.
  - *لماذا*: يقلل استهلاك الذاكرة وعمليات إعادة الرسم في المتصفح (Repaints/Reflows)، مما يمنح مشغل الفيديو (`HLS.js` أو المشغل المدمج) كامل قوة المعالج والبطاقة الرسومية دون تقطيع.
- **القرار 3: تسلسل الأولويات قبل التراجع للمشغل المدمج**
  - *النهج المختار*: فحص السيرفرات الأربعة عبر الـ Worker وفق ترتيب سرعتها، وتجربة كافة الروابط المستخرجة من السيرفر الأول ثم السيرفر الثاني والثالث والرابع قبل الانتقال إلى المشغل المدمج (`iframe`) الذي يعمل بدوره بدون قيود `sandbox`.

## 4. المعمارية التقنية واستراتيجية البيانات

### مخطط المعمارية وتدفق التشغيل

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    واجهة المشغل السينمائي (Theater UI)                  │
│  • توسع مسرحي (92vw / max-w-6xl) عند تشغيل الفيلم فقط                  │
│  • شريط علوي شفاف وخفيف (التريلر · العودة للخلفية · ملء الشاشة · إغلاق)│
│  • مجسم التحميل البصري (Animated Eye Loader) بدون أي نصوص              │
│  • فصل كامل لشبكة الأفلام الخلفية وتفاصيل القصة والممثلين أثناء العرض   │
└───────────────────────────────────┬─────────────────────────────────────┘
                                    │ ضغطة واحدة على (Watch Now)
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│             مراقب سرعة السيرفرات الذكي (Server Speed Monitor)           │
│  • يقرأ سجل سرعات السيرفرات من الكاش (Latency ms + Success Rate)       │
│  • يرتب السيرفرات الأربعة [الأسرع أولاً -> الأبطأ أخيراً]               │
│  • يقيس زمن بدء التشغيل الفعلي ويحدّث الترتيب في الكاش تلقائياً         │
└───────────────────────────────────┬─────────────────────────────────────┘
                                    │ مصفوفة السيرفرات المرتبة حسب السرعة
                                    ▼
┌─────────────────────────────────────────────────────────────────────────┐
│          محرك استخراج الفيديو والترجمة (Cloudflare Worker Engine)       │
│  • اتصال سريع مع كاش الجلسة ومهلة زمنية ذكية (AbortController)         │
│  • استخراج روابط البث (.m3u8 / .mp4) + المشغل الداخلي + ملفات الترجمة   │
│  • الأولوية: تجربة السيرفر التالي عند تعذر السيرفر الحالي               │
└─────────────────┬───────────────────────────────────┬───────────────────┘
                  │ نجاح استخراج البث                 │ بعد استنفاد الاستخراج
                  ▼                                   ▼
┌───────────────────────────────────┐ ┌───────────────────────────────────┐
│   مشغل البث الأصلي (HLS / Video)  │ │   المشغل المدمج المباشر (Iframe)  │
│ • تشغيل عبر proxiedUrl + HLS.js   │ │ • يبدأ بأسرع سيرفر بدون Sandbox   │
│ • تركيب ملفات الترجمة <track>     │ │ • تبديل تلقائي للسيرفر التالي     │
└───────────────────────────────────┘ └───────────────────────────────────┘
```

### تفاعل المكونات وإدارة الحالة

- **مراقب السرعة (`Server Speed Monitor`)**:
  - يسجل لحظة بدء الطلب (`performance.now()`) ولحظة جاهزية الفيديو (`onLoadedData` / `MANIFEST_PARSED` / `onLoad`) ليحسب زمن الاستجابة الفعلي بالملي ثانية ويحفظه في الكاش.
- **حالة التركيز السينمائي (`isWatchingInGallery`)**:
  - عند تفعيلها: تُخفي شبكة الأفلام الخلفية وتُخفي قسم القصة وطاقم التمثيل، وتُظهر فقط مسرح الفيديو (وشريط المواسم/الحلقات إذا كان المحتوى مسلسلاً).
  - عند الضغط على زر العودة للخلفية أو إغلاق النافذة: تعود تفاصيل الفيلم وشبكة الموقع للظهور فوراً بالحجم القياسي.
